# 大腸息肉切除後追蹤間隔計算機 (Polyp Surveillance Interval Calculator)

這是一個基於 **USMSTF (美國多學會任務小組) 2020 年更新指引**所開發的互動式單頁網頁應用程式 (PWA)。旨在協助胃腸肝膽科醫師，根據大腸鏡檢查品質與病理報告結果，快速且準確地推導出病患下一次的大腸鏡追蹤建議時間。

## 專案特色

*   **權威指引為基礎**：內建 USMSTF 2020 複雜的決策樹邏輯，涵蓋管狀腺瘤 (Tubular Adenoma)、無蒂鋸齒狀病灶 (SSL/SSP)、傳統鋸齒狀腺瘤 (TSA) 及進階病理特徵。
*   **純前端端側運算**：採用 Vue.js 進行即時邏輯判斷，所有運算皆在使用者裝置的瀏覽器內完成，無後端資料庫，確保病患隱私零外洩風險。
*   **響應式與 PWA 支援**：使用 Tailwind CSS 打造跨裝置友善介面，並內建動態 Manifest。支援將網頁直接「加入主畫面」成為手機上的原生 App，方便門診或內視鏡室快速調閱。
*   **零相依性 (Zero Dependencies)**：所有程式碼皆封裝於單一 HTML 檔案中，無需繁瑣的 npm 安裝或建置步驟。

## 醫學決策邏輯 (依據 USMSTF 2020)

系統將自動判斷以下核心情境並給出建議：

1.  **分片切除 (Piecemeal Resection)**：≥ 20mm 腺瘤或鋸齒狀病灶若採分片切除 ➜ **6 個月**。
2.  **極高風險**：超過 10 顆腺瘤 ➜ **1 年**。
3.  **高風險 / 進階腺瘤 (Advanced Adenoma)**：1 顆以上 ≥ 10mm、絨毛狀 (Villous) 或高度異生 (High-Grade Dysplasia) ➜ **3 年**。
4.  **中風險**：3-4 顆小於 10mm 管狀腺瘤 ➜ **3-5 年**；5-10 顆 ➜ **3 年**。
5.  **低風險**：1-2 顆小於 10mm 管狀腺瘤 ➜ **7-10 年**。
6.  **無異常或微小增生性息肉**：大腸鏡正常或僅有 ≤ 10mm 位於直腸/乙狀結腸的增生性息肉 ➜ **10 年**。
7.  **鋸齒狀病灶 (Serrated Lesions)**：依據大小、數量與是否伴隨異生 (Dysplasia) 區分 3 年或 5 年追蹤。

*(註：本計算機預設前提為「高品質大腸鏡檢查」，即盲腸到達率達標且清腸程度良好 (BBPS ≥ 6)。若清腸不佳，指引建議 1 年內重做)*

## 檔案結構

*   `polyp-surveillance-pwa.html`: 包含 HTML 架構、Tailwind 樣式、Vue 運算邏輯與 PWA 安裝機制的完整原始碼檔案。
*   `README.md`: 本說明文件。

## 部署與使用方式

本專案為純前端架構，部署極為簡易：

1.  將 `polyp-surveillance-pwa.html` 檔案上傳至任何靜態網頁代管服務（例如：GitHub Pages）。
2.  取得專案網址後，在手機或平板的瀏覽器（Safari 或 Chrome）中開啟。
3.  點擊瀏覽器的分享按鈕或選單中的「加入主畫面 (Add to Home Screen)」，即可在裝置桌面上建立 App 圖示，享受全螢幕的互動體驗。

## 聲明與免責條款

本互動網頁僅為臨床決策輔助工具 (Clinical Decision Support Tool)，其結果基於 USMSTF 2020 準則。實際臨床處置仍須由主治醫師考量病患家族史、共病症、過去切除史及個人健康狀況後，進行最終的專業醫療判斷。
